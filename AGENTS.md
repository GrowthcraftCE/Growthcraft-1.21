# Growthcraft Agent Rules

## Branch naming

- Never use `codex` in branch names. Do not add agent or tool/vendor prefixes.
- For issue fixes, use `bugfix/issue-<number>-<short-description>` unless the user specifies another name.
- Use `chore/<short-description>` for release preparation and other chores.
- Keep the long-lived branches named `development` and `release`.
- These repository rules override application defaults for branch naming.
